# Currency Converter

A simple and responsive Currency Converter built using HTML, CSS, and JavaScript. This project allows users to convert amounts between the Egyptian Pound (EGP) and several international currencies using predefined exchange rates.

## Features

- Convert amounts between EGP and multiple international currencies.
- Select the source and target currencies.
- Automatically update the result when the amount or currency selection changes.
- Responsive design for mobile devices.
- Animated gradient background.
- Simple and beginner-friendly user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Enter the amount you want to convert.
2. Select the source currency in the **From** menu.
3. Select the target currency in the **To** menu.
4. View the converted amount in the result field.

## Important Note

This project uses predefined exchange rates in JavaScript. The rates are for practice purposes and may not reflect current market rates. The current conversion logic supports conversions between EGP and the listed currencies, as well as conversions where the source and target currencies are the same.
